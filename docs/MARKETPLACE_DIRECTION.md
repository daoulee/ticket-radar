> **2026-11-10 사용자 결정(최신):** 양도가는 판매자가 입력한 원 구매가 이하이면서, 같은 공연·회차·등급의 확인된 기준가 이하여야 한다. 더 낮은 양도가도 허용한다. 원 구매가의 진위는 확인되지 않았다. 브라우저·가상 시연 기준가와 실제 공식 정가를 구분한다. 서버 연결형 거래의 원 구매가 입력·검증은 별도 계약 확인이 필요하다.

# 티켓레이더 방향 변경 · 대회 시연

## 사용자 결정

- 티켓레이더는 공식 최초 예매와 개인 간 티켓 양도를 중심으로 합니다. 기존 판매글·공식 안내 대조는 구매를 돕는 부가 기능입니다.
- 공식 예매를 플랫폼 안에서 처리하는 것이 목표다. 현재 주최 측 판매 권한과 실제 재고는 확보되지 않아 이번 시연에서는 가상 공연·좌석을 사용합니다.
- 개인 간 양도는 판매자의 원구매가와 등록가가 같은 매물만 허용합니다. 원구매가와 티켓 보유 여부의 진위 검증은 별도 근거가 없으면 보장하지 않습니다.
- 판매자가 매물을 등록하고 구매자가 선택해 결제 직전의 확인 단계까지 진행합니다. 이번 시연에서 실제 결제·정산·좌석 예약·티켓 이전은 수행하지 않습니다.
- 임의로 생성한 매물은 시연용 가상 매물로 명확히 표시합니다. KOPIS의 실제 공연 목록은 공연 정보이며 당사 플랫폼의 공식 판매권·좌석 재고·양도 허용 근거가 아닙니다.

## 시연 흐름

1. 구매자는 가상 공식 예매와 가상 양도 매물 중 선택합니다.
2. 공연·회차·좌석·수량·가격과 양도 조건을 살펴본다.
3. 구매 확인 단계에서 거래 방식과 합계, 시연 및 결제 미실행 사실을 확인합니다.
4. 판매자는 가상 양도 매물을 등록하며 원구매가와 등록가의 일치 여부를 확인합니다.
5. 선택적으로 기존 판매글 정보 추출·공식 안내 대조를 이용합니다. 실제 공연의 데이터가 없으면 비교를 보류합니다.

## 현재 상태와 작업 경계

- 기존 공개 웹은 KOPIS 공연 검색 및 가상 공연의 판매글 대조를 제공합니다. 이번 방향의 판매·구매 플랫폼이 완성된 것은 아닙니다.
- 기존 서버의 분석 로직 일부는 특정 공연의 데이터에 맞춰져 있습니다. 이를 다른 공연에 범용 검증 기능처럼 적용하지 않습니다.
- 작업 분배: 공통 계약·도메인 규칙은 서버 담당, 웹 시연 UI는 웹 담당, 앱은 웹·계약 확정 뒤 연결합니다. Astra는 통합과 검증을 맡는다.
- 데이터 저장 범위, 판매 권한·재고 연동, 실제 결제 수단 및 운영 모델은 별도 확인 전까지 시연용으로만 취급합니다.

## 운영 전 확인

- 최초 판매 및 양도 허용 여부는 공연·예매처별 공식 조건과 판매 권한을 확인합니다.
- 구매가 일치 정책은 제품 정책입니다. 이것만으로 법적 적법성·본인 보유·티켓 진위·입장 가능성을 보장하지 않습니다. 적용 법령과 중개·결제 운영 요건은 실제 운영 전 확인합니다. 참고: [공연법 제4조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1025609297).
- 주문 경쟁·중복 판매, 취소·환불, 개인정보, 결제·정산 책임은 실제 거래 도입 전 설계가 필요합니다.
