## 코드 통합 경계
작업자는 읽기 전용으로 코드 근거와 diff를 반환했다. Astra가 경로·내용을 검토해 제안을 적용하고 테스트했다. 자동 원본 대화 메시징이나 에이전트의 직접 파일 편집을 주장하지 않는다. 제안 diff의 hunk 좌표가 맞지 않아 git apply 검사 실패 후 원문 일치 여부를 확인한 텍스트 치환으로 반영했다. 일부 테스트 명령의 작업 디렉터리 오류는 올바른 경로에서 재실행했다.
