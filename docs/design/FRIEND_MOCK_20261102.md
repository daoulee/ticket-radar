## 홈 구조

작은 상단 로고/제목 → ‘티켓 판매글, 결제 전에 공식 안내와 맞춰 보세요’ hero → 짧은 설명 → StepsCard(1 입력, 2 확인·수정, 3 공식 대조) → ShowCard(현재 확인 가능한 공연 제목/시간/장소/공식 링크) → 하단 pill CTA ‘판매글 확인하기’ → 짧은 참고용 안내.

현재 제품에 맞춘 조정:
- capture 업로드는 미구현이므로 ‘판매글을 붙여넣어요’로 표시.
- fixture/manual을 AI가 실제 읽은 결과로 표현하지 않는다.
- 공연 예시는 실제 API/fixture 목록에서 가져온다. 목업의 `○○ 콘서트`를 실제 공연으로 하드코딩하지 않는다.
- 기존 /events 선택 단계와 조건 확인 로직을 유지한다. 홈에서는 제공 가능한 공연 요약과 공연 선택 진입을 보여준다.
- 로고는 기존 임시 심벌을 사용하고 사용자 제작본이 오면 교체한다.

## 누락 파일과 효과 한계

Pen이 `screen-glow.glsl`, `dashed-pill.glsl`, `suno-cta.glsl` 미존재 오류를 반환했다. Downloads/AID에서 같은 이름을 찾아도 없었다. 따라서 Pen 스크린샷의 분홍색 오류 배경을 디자인 색으로 사용하면 안 된다.

사용자에게 부속 폴더 경로를 물었으며, 아직 경로를 받지 않았다. 원본 shader 효과는 정확히 재현할 수 없다. 우선 색상 토큰·레이아웃을 적용하고, 네이티브 표준 표면/테두리/기본 포인트색으로 표시한다. 제공받으면 효과를 별도 반영한다. 새 기능·새 의존성을 무단 도입하지 않는다.
