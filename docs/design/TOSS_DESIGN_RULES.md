# 토스(toss.im) 디자인 규칙 추출 → 티켓레이더 각색안

- 작성: 2026-11-02, Claude Code (claude-opus-5-5), 사용자 요청 "디자인 규칙만 전부 가져와, 우리 식으로 각색"
- 출처: `https://toss.im` 공개 HTML 1개 + 공개 CSS 11개(약 262KB)를 내려받아 **값의 빈도만 집계**. 토스 코드·이미지·아이콘·폰트(Toss Product Sans, Tossface)는 복사·포함하지 않음.
- 한계: 크롬 확장 미연결로 **렌더링된 화면은 보지 못함**. 본문은 JS로 그려져 HTML에서 문구/섹션 구조는 확인 불가(메뉴: 서비스·비즈니스·회사소개·뉴스룸·채용·앱 다운로드만 보임). 아래 "관찰 규칙"은 CSS 수치 근거, "해석"은 추정임을 구분.
- 우선순위: 팀 기준은 여전히 [FRIEND_MOCK_20261102.md](FRIEND_MOCK_20261102.md)(Pen 팔레트)다. 이 문서는 **색을 바꾸지 않고, 토스의 "쓰는 방식(규칙)"만 우리 토큰에 입힌다.**

## 1. 색 — 규칙: "포인트 색 1개 + 푸른 기가 도는 회색 9단계 + 검정 대신 남색 투명도"

### 관찰 (CSS 등장 횟수)
| 역할 | 토스 값 | 횟수 |
|---|---|---|
| 유일한 포인트(파랑) | `#3182f6` | 60 |
| 포인트 눌림/진하게 | `#2272eb`, `#1b64da` | 6, 7 |
| 포인트 옅은 배경 | `#e8f3ff`, `#c9e2ff`, `#90c2ff` | 29, 7, 4 |
| 위험(빨강) / 배경 | `#f04452` / `#ffeeee` | 28 / 11 |
| 회색 단계 | `#f9fafb` `#f2f4f6` `#e5e8eb` `#d1d6db` `#b0b8c1` `#8b95a1` `#6b7684` `#4e5968` `#333d4b` | – |
| 보조 상태색(드물게) | 초록 `#03b26c`/`#029359`, 주황 `#dd7d02` | 2~4 |
| 반투명 텍스트 | `rgba(0,12,30,.8)` 본문, `rgba(3,24,50,.46)` 보조 | 16, 19 |
| 반투명 면/선 | `rgba(2,32,71,.05)`, `rgba(0,27,55,.1)`, `rgba(0,23,51,.02)` | 55, 57, 26 |

### 해석 → 우리 규칙
1. 화면에서 **채도 높은 색은 포인트 1개(+위험 빨강)** 만 쓴다. 나머지는 전부 회색.
2. 회색은 **순수 회색이 아니라 남색 기운**이 있다(R<G<B). 그림자·구분선·흐린 글씨도 `rgba(검정)`이 아니라 `rgba(남색, α)`.
3. 상태 배경은 "포인트색의 아주 옅은 버전 + 진한 글씨" 짝으로만 쓴다.

### 티켓레이더 매핑 (Pen 팔레트 유지)
| 역할 | 토스 | **티켓레이더** |
|---|---|---|
| primary | `#3182f6` | `#2563EB` (Pen 그대로) |
| primary-pressed | `#1b64da` | `#1D4ED8` |
| primary-weak 배경 | `#e8f3ff` | `#DBEAFE` |
| danger / bg | `#f04452` / `#fee` | `#DC2626` / `#FEE2E2` |
| warning(확인 필요) | `#dd7d02` | `#C2410C` / `#FFEDD5` (Pen) |
| safe(정상) | `#03b26c` | `#047857` / `#D1FAE5` (신규 제안) |
| ink / sub / weak | `#333d4b` / `#6b7684` / `#b0b8c1` | `#0B1220` / `#5A6478` / `#8A94A6` (Pen) |
| line | `#e5e8eb` | `rgba(11,18,32,.08)` |
| shadow tint | `rgba(0,27,55,…)` | `rgba(11,18,32,…)` (우리 ink 기준) |

> 판정 화면에서 **위험=빨강, 확인 필요=주황, 정상=초록**은 결과 배지에만 쓰고, 그 외 UI는 파랑+회색만. (토스가 빨강을 오류에만 쓰는 방식과 동일한 절제)

## 2. 타이포 — 규칙: "자간은 항상 살짝 좁게, 굵기는 4~5단계, 본문 행간 넉넉"

### 관찰
- 자간: `-0.02em` 11회 / `-0.01em` 2회 → **거의 모든 텍스트에 음수 자간**
- 굵기: 400(30) · 500(32) · 600(29) · 700(30) · 800(12, 큰 제목 전용)
- 행간: 본문 `1.6`(19회), 제목 `1.2~1.34`, 버튼 `1.4~1.5`
- 크기 단계(px): 12 · 13 · 14 · 15 · 16 · 17 · 18 · 19 · 20 · 24 · 28 · 32 · 36 · 40 · 48 · 56 · 64
  - 작은 쪽은 1px 단위로 촘촘, 큰 쪽은 4~8px 점프 → **본문은 미세 조정, 제목은 과감한 대비**
- 폰트 스택: 전용 서체 → 시스템(-apple-system, Apple SD Gothic Neo) → Noto Sans KR 순 대체

### 티켓레이더 적용
| 토큰 | 크기/행간/굵기 | 용도 |
|---|---|---|
| display | 48 / 1.2 / 800 (모바일 32) | 결과 판정 문장 "판매가가 공식가보다 2.4배 높아요" |
| h1 | 32 / 1.25 / 700 | 페이지 제목 |
| h2 | 24 / 1.3 / 700 | 섹션 제목 |
| title | 20 / 1.4 / 600 | 카드 제목 |
| body | 16 / 1.6 / 400 | 본문 |
| body-strong | 16 / 1.6 / 600 | 강조 수치 |
| sub | 14 / 1.5 / 500 | 보조 설명 |
| caption | 12~13 / 1.5 / 500 | 출처, 시각 |

- 공통 `letter-spacing: -0.02em`.
- 폰트: **Pretendard**(무료, 오픈 라이선스) 권장. Pen은 Noto Sans KR이지만 웹은 Pretendard가 토스 느낌에 더 가깝다 — 앱과 맞출지 Astra 결정 필요.
- 숫자(가격)는 `font-variant-numeric: tabular-nums`로 자릿수 정렬.

## 4. 그림자·테두리 — 규칙: "테두리 대신 그림자/링, 그림자는 두 겹으로 아주 흐리게"

### 관찰
- 카드 기본: `0 2px 10px rgba(0,27,55,.1), 0 3px 20px rgba(2,32,71,.05)` ← 두 겹
- 떠 있는 요소: `0 4px 20px 0 rgba(0,27,55,.1)`
- 모달급: `0 0 15px …(.1), 0 0 60px …(.05)`
- **포커스/선택 링(가장 특징적)**: `inset 0 0 0 1.5px <색>, 0 0 0 2px <옅은 색>`
  - 파랑: `#3182f6` + `#e8f3ff` / 오류: `#f04452` + `#fee` / 기본: `#4e5968` + `rgba(0,27,55,.1)`
  - 즉 **안쪽 1.5px 진한 선 + 바깥 2px 옅은 후광**. `border`를 안 써서 레이아웃이 흔들리지 않음.

### 티켓레이더 적용
```css
--tr-shadow-card:  0 2px 10px rgba(11,18,32,.08), 0 3px 20px rgba(11,18,32,.04);
--tr-shadow-float: 0 4px 20px rgba(11,18,32,.10);
--tr-ring-focus:   inset 0 0 0 1.5px #2563EB, 0 0 0 2px #DBEAFE;
--tr-ring-danger:  inset 0 0 0 1.5px #DC2626, 0 0 0 2px #FEE2E2;
--tr-ring-neutral: inset 0 0 0 1.5px #5A6478, 0 0 0 2px rgba(11,18,32,.08);
```
→ 판매글 입력창 포커스, 선택된 공연 카드, 위험 항목 카드 강조에 그대로 활용.

## 5. 크기·간격 — 규칙: "컴포넌트 높이는 고정 단계, 간격은 4의 배수"

- 컴포넌트 높이 토큰: 16·18·20·22·24·**32·40·48·56** (촘촘판: 24·28·34·40·46)
  - 우리: 칩 32, 보조 버튼 40, **기본 버튼/입력 48(터치 최소 48 규칙과 일치)**, 메인 CTA 56 (Pen 54 → 56 권장)
- gap 빈도: 8(12) · 4(7) · 6 · 24 · 12 · 16 · 40 → 우리 `space` 4·8·12·16·24·32·48 유지(이미 일치)
- 아이콘 버튼 최대 44px

## 6. 레이아웃·반응형

- 콘텐츠 최대폭: `1064px`, `1120px`(본문 컨테이너), 전체 상한 `1920px`, 좁은 패널 `430px`(모바일 프레임 폭)
- 브레이크포인트: 640 · 768 · 810 · 1024 · 1280 · 1440 · 1600
- 티켓레이더: 컨테이너 `max-width: 1120px; padding: 0 24px`(모바일 16), 결과 화면 본문은 `720px` 한 줄 읽기 폭, 브레이크포인트 640/1024/1280 세 개만 사용.

---

## 7. 움직임 — 규칙: "짧고(0.1~0.2s) 속성별로 다르게"

- 기본 `.2s` (배경, 그림자, 테두리), 글자색은 더 빠르게 `.1s`, 눌림 `.15s`
- 헤더 배경 전환 `.4s ease` (스크롤 시 투명→유리 효과)
- 입장 애니메이션은 `@media (prefers-reduced-motion: no-preference)` 안에서만
- hover 효과는 `@media (hover: hover)` 안에서만 → 모바일에서 hover가 붙어 남지 않음
- "앱 다운로드" 버튼 문구가 **글자 단위로 쪼개져** 있음(HTML 근거) → 글자별 순차 애니메이션 추정
- 자동완성 노란 배경 제거: `transition: background-color 5000s` 트릭

티켓레이더: 기존 `motionMs`(press 120 / disclosure 180 / content 200)와 거의 일치 → 유지. 결과 판정 숫자는 0→값 카운트업(700ms 이내, brandMax 준수).

## 8. 유리 효과 헤더

- `backdrop-filter: blur(20px)`(10회), `blur(30px)`(6회), 바탕 `rgba(253,253,255,.75)`
- 적용: 상단 고정 헤더 `background: rgba(255,255,255,.75); backdrop-filter: blur(20px)` + 스크롤 시 하단 `--tr-line` 표시.


## 10. 각색 포인트 (토스와 달라야 하는 부분)

- 토스는 "돈을 쉽게" → 밝고 경쾌. 티켓레이더는 "**속기 전에 확인**" → 결과 화면은 **판정 배지 + 근거 목록**으로 신뢰감 우선(VirusTotal식 구조).
- 토스 파랑 `#3182f6` 대신 Pen 파랑 `#2563EB`, CTA는 Pen 그라디언트(#2563EB→#38BDF8) 유지 → 한눈에 토스로 보이지 않음.
- 전용 폰트·Tossface 이모지·일러스트 사용 금지. 아이콘은 Lucide 등 오픈 라이선스.
