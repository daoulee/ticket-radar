총 **18개 독립 화면**과 화면 지도 1개다. 기존 가져오기 보드는 참고용으로 보존했다. 후속 화면은 구현 결정이나 운영기관 연동 완료를 뜻하지 않는다. Pen 목업은 정적이며 화면 간 클릭 동작은 연결하지 않았다. 공연·가격·판매글은 합성 시연 자료다.
