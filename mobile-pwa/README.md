# 티켓레이더 모바일 앱

[티켓레이더 웹](https://ticketradar.month32.workers.dev/)을 모바일 앱처럼 쓸 수 있게 만든 PWA입니다.
홈 화면에 추가하면 주소창 없이 앱처럼 열립니다.

> 모든 공연, 가격, 거래, 결제는 시연용 가상 데이터입니다. 실제 티켓 발급이나 결제는 없습니다.

## 화면
- **홈**: 검색바, 자동 넘김 배너, 퀵메뉴, 인기 공연, 원가 양도 새 글
- **탐색**: 카테고리 칩 + 검색, 최근 본 공연
- **양도**: 스토리 + 피드 (더블탭 좋아요, 저장, 공유)
- **내 티켓**: 가상 예매 티켓, 30초마다 바뀌는 입장 코드
- **MY**: 찜·예매 현황, 알림 설정, 앱 설치
- **공연 상세 → 바텀시트 예매 → 가상 결제**
- **판매글 확인**: 양도 판매글을 공식 가격·입장 규정과 대조 (예시 3종)

## 구조
빌드 도구 없이 바로 배포되는 정적 사이트입니다.

```
public/
  index.html             앱 셸
  styles.css             스타일
  app.js                 화면·라우팅·데이터
  manifest.webmanifest   PWA 매니페스트
  sw.js                  오프라인 캐시 서비스워커
  icons/                 앱 아이콘
netlify.toml             Netlify 배포 설정 (publish = public)
```

## 로컬 실행
```bash
npx http-server public -p 5180 -c-1
```

## 휴대폰에 설치
- **안드로이드(Chrome)**: 사이트 접속 → 설치 배너의 **설치** 또는 메뉴(⋮) → **앱 설치**
- **아이폰(Safari)**: 사이트 접속 → 공유 버튼 → **홈 화면에 추가**
