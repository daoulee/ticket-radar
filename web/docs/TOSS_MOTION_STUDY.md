# toss.im 스크롤 연출 관찰 → 티켓레이더 클린룸 재구현 명세

- 작성: 2026-11-02, 웹 담당(Opus 1 역할) / claude-opus-5-5. 사용자 요청("토스 페이지 뜯어보고 우리 것으로 재창작").
- 방법: Playwright(설치된 Chrome)로 `https://toss.im/`을 1280×900·390×844에서 실제 렌더링하고, 화면 높이의 절반 간격으로 스크롤하며 스크린샷과 요소의 위치·글자 크기·투명도·transform·position을 기록했다. 공개 HTML·JS는 프로젝트 밖 임시 폴더에 받아 **키워드만 검색**했다(실행·복사 안 함).
- 원칙: 토스의 코드·이미지·영상·문구·폰트·아이콘은 이 저장소에 넣지 않는다. 아래는 관찰한 **동작**을 숫자로 적은 것이고, 티켓레이더 구현은 이 명세만 보고 새로 작성했다.

## 1. 관찰 요약

| # | 관찰한 연출 | 근거(측정값) |
| --- | --- | --- |
| A | 페이지 길이: 데스크톱 50,522px, 모바일 21,016px. 섹션마다 화면 높이(900px)짜리 sticky 무대가 여러 개 겹쳐 있다 | `position: sticky` DIV h=900 다수, 상단 fixed 헤더 64px |
| B | 첫 화면: 전면 사진 위에 제목을 세 덩어리로 화면 아래쪽에 넓게 벌려 놓음. 스크롤하면 전면 화면이 여백·둥근 모서리가 있는 카드로 줄어든다 | 4번째 프레임 전면 사진, 13번째 프레임에서 둥근 카드(좌우 약 140px 여백) |
| C | 왼쪽 가장자리에 세로 대시 목록(현재 섹션만 진하게)이 고정 | 화면 좌측 x≈30 대시 10여 개 |
| D | 큰 제목이 **1.8배 확대된 상태에서 제자리(1배)로 줄어들며** 들어온다 | `matrix(1.8,0,0,1.8,0,268)` → `matrix(1,0,0,1,0,0)` |
| E | 본문·부제는 스크롤에 연동돼 **아래 40px·투명 0에서 제자리·1로** 올라온다(시간 애니메이션이 아니라 스크롤 위치 비례) | op 0.36~0.72, translateY 15.5·6.8 같은 중간값 관찰 |
| F | 두 단어 제목이 스크롤에 따라 **좌우로 갈라지며 사라진다** | "온오프라인"/"경계 없이" translateX ±107 → ±635, op 1 → 0.004 |
| G | 짧은 단어를 한 줄에 하나씩 쌓아 큰 글씨(56px)로 하나씩 보여준다 | "매일/하는/쇼핑도/이제는/토스로" |
| H | sticky 무대 안에서 기능 설명 패널이 차례로 **교차 페이드**된다 | 한 패널 op 0.52 / 다음 패널 op 0 → 0.99 |
| I | 링크·버튼 글자를 한 글자씩 쪼개 두 번 써 두고, hover 시 글자가 위로 굴러 바뀐다 | 텍스트가 "내 자산내 자산"처럼 글자 단위로 2회 반복된 A 요소 |
| J | 숫자를 자릿수별로 쪼개 굴러가는 계수기 | "2,810" 자릿수 분리 |
| K | 구현: 애니메이션 라이브러리(GSAP 등) 흔적 없음. 번들 안에 `MotionValue`·`stiffness`·`damping`·`initial/animate/exit` → 스프링 물리 기반 React 모션 라이브러리를 번들해 사용하는 것으로 추정. IntersectionObserver·requestAnimationFrame 사용 | 키워드 집계 |

## 2. 티켓레이더 적용 명세(클린룸)

| 관찰 | 적용 여부 | 우리식 구현 |
| --- | --- | --- |
| B 전면 → 카드 축소 | 적용 | 히어로를 sticky 무대로 바꾸고, 배경 무대 패널이 스크롤 `--p`에 따라 전면(여백 0·반경 0) → 카드(여백 24px·반경 32px)로 줄어든다. 사진 대신 우리 티켓 일러스트·광원 |
| C 세로 섹션 표시 | 적용(데스크톱) | 왼쪽 고정 대시 목록, 현재 섹션 강조, 클릭 시 해당 섹션으로 이동. 모바일 숨김 |
| D 큰 제목 확대 → 제자리 | 적용 | 스토리 구간 제목 `scrub-zoom`: scale 1.5→1, translateY 80→0 |
| E 스크롤 비례 등장 | 이미 적용(`scrub-in`) | 거리 40px로 맞춤 |
| F 단어 좌우 분리 | 적용(반대 방향) | 마지막 섹션 "직접 / 확인해 볼까요?"가 좌우에서 모여 한 줄이 된다 |
| G 단어 쌓기 | 적용 | "이 말들, / 어디까지 / 믿어도 / 될까요?" 단어별로 순서대로 등장 |
| H 교차 페이드 | 보류 | 현 3단계 목록 유지(내용 탐색성 우선) |
| I 글자 굴림 hover | 적용 | CTA·헤더 버튼. 보조기기에는 원래 문구 1번만(aria-label), 시각 글자는 aria-hidden |
| J 숫자 계수기 | **미적용** | 가격 숫자를 굴리면 카운트업과 같은 효과 → DESIGN_SPEC D11(가짜 진행·카운트업 금지) |
| K 스프링 물리 | 적용(의존성 없이) | CSS `linear()` 이징으로 살짝 넘쳤다 돌아오는 스프링 곡선 근사. 새 패키지 설치 없음(D12) |
| 관성 스크롤 | **미적용** | 스크롤 가로채기는 키보드·보조기기·모션 축소 사용자에게 불리 |

모든 효과는 `prefers-reduced-motion: no-preference`에서만 동작하고, 모션 축소·IntersectionObserver 미지원이면 정지 상태로 전부 보인다(WEB-008 원칙 유지).
